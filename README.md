# Chinmay Biswal Portfolio
Run: open `index.html` in a browser (needs internet for Bootstrap, jQuery and Montserrat CDNs). Or `python3 -m http.server` in this folder.
Demo images/videos live in `images/` (portrait, about, `work/`, `videos/`). Replace them with your real files using the same names. The CV is in `assets/`.
Content is written directly in index.html. Add portfolio items by copying a <button class="item"> block. Replace social href="#" with your real profile URLs.
